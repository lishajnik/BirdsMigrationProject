# BirdsMigrationProject
# Информационная система мониторинга миграции птиц «Love Birds Forever»

SPA-приложение для визуализации, предиктивного анализа и выявления математических аномалий в поведении перелетных птиц на основе реальных данных орнитологической сети eBird.

# Стек технологий
**Frontend:** React.js, JSX, CSS3.
**Backend:** Flask (Python), sqlite3.
**Data Science & Аналитика:** Pandas, NumPy.
**Интеграция:** eBird API, OpenPyXL

## Ключевой аналитический функционал
1.  **Детекция аномалий (Z-Score):** Автоматический расчет среднеквадратичного отклонения размеров стаи. Флаг аномалии выставляется налету методами Pandas.
2.  **Сложные SQL-подзапросы:** Вывод сводных данных ТОП-3 аномальных видов птиц, чья численность строго превышает средние показатели по всей базе данных (реализовано через подзапросы, `HAVING` и `AVG()` на стороне SQLite).
3.  **Предиктивные тренды:** Построение прогнозных графиков на основе среднеквадратичных трендов NumPy.

## Инструкция по локальному развертыванию

### 1. Настройка Бэкенда (Flask)
Перейдите в папку с бэкенд-кодом проекта(BirdsMigrationProject/backend):
```bash
#Сначала убедитесь что оболочка активна(в начале строки написано PS)
# Установка необходимых зависимостей
pip install -r requirements.txt

# Запуск сервера Flask (по умолчанию на порту 5000)
python runserver.py
```

### 2. Настройка Фронтенда
```bash
# Установка npm-пакетов
npm install

# Запуск локального сервера разработки React(сначала надо перейти в папку frontend)
npm run dev
```
